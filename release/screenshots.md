# Screenshot Plan

The screenshots should show real in-app screens with realistic demo data. Avoid private member emails, real phone numbers, or real church member names unless you have permission.

## Official Specs Checked

- Apple App Store Connect currently accepts 1 to 10 screenshots per device set in JPEG, JPG, or PNG, with no alpha channels or transparency.
- For modern iPhone listings, capture or export 6.9 inch portrait screenshots at one accepted size such as 1290 x 2796, 1260 x 2736, or 1320 x 2868.
- Google Play supports up to 8 screenshots per device type. For phone screenshots, use PNG or JPEG with no alpha, and prefer 1080 x 1920 portrait screenshots.
- Google Play feature graphic must be 1024 x 500, JPEG or 24-bit PNG with no alpha.

Official references:

- Apple screenshot specifications: https://developer.apple.com/help/app-store-connect/reference/app-information/screenshot-specifications
- Google Play preview assets: https://support.google.com/googleplay/android-developer/answer/9866151

## Recommended Screenshot Set

Use 6 screenshots for both stores. This is enough to explain the app without making the listing feel heavy.

1. Schedules overview
   - Show the church name header, upcoming services, assigned roles, and notification bell.
   - Caption idea: "See every upcoming service at a glance"
   - Alt text: "Schedules screen showing upcoming worship services and team assignments."

2. Service details and song list
   - Show a service card with role assignments and song selections.
   - Caption idea: "Keep songs and service details together"
   - Alt text: "Service details screen showing assigned members and song selections."

3. Fill-in request
   - Show the fill-in request flow or an active request notification.
   - Caption idea: "Request help from members with the same role"
   - Alt text: "Fill-in request screen for a scheduled worship role."

4. Notification history
   - Show the bell notification list with reminders or fill-in messages.
   - Caption idea: "Review reminders and team updates"
   - Alt text: "Notification history showing service reminders and team updates."

5. Profile availability
   - Show the Profile calendar with unavailable dates selected.
   - Caption idea: "Mark unavailable dates before scheduling"
   - Alt text: "Profile screen with a calendar for unavailable dates."

6. Admin church tools
   - Show the Church tab with members, roles, recurring services, reminder settings, or song type management.
   - Caption idea: "Manage members, roles, reminders, and song types"
   - Alt text: "Admin church tools for members, roles, reminders, and song types."

## Capture Checklist

- Use light mode unless dark mode looks clearly better.
- Hide the keyboard before every screenshot.
- Make sure no loading spinners, modals, or test error messages are visible unless that is the intended screenshot.
- Make sure the bottom tab bar does not cover important content.
- Use clean demo names and avoid exposing real user emails in screenshots.
- Capture the iOS set from a large iPhone simulator or real device.
- Capture the Android set from a Pixel-style emulator or real device at 1080 x 1920.

If you create framed marketing screenshots, keep the captions short:
